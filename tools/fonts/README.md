# Fonts used by tools/make_logo.py

- `Inter-SemiBold.ttf`, `Inter-Bold.ttf`: Inter 4.1 by Rasmus Andersson, static TTFs from
  `extras/ttf/` of the official release archive
  https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip
  (release page: https://github.com/rsms/inter/releases/tag/v4.1).
- Licence: SIL Open Font License 1.1, full text in `OFL.txt` (the release's `LICENSE.txt`).

The logo SVGs contain the letters as outlines, so they do not need the font at view time.
