    SLEvolve v1.0¶

    SLEvolve was developed by Xiyuan Bao. It combines an exact recursive reformulation of the viscoelastic memory, engineering optimizations of the solver, and physics-inspired iteration starts; the implementation was AI-agent-assisted, with the formulation, the algorithms and the acceptance criteria set by the author and every change verified against the legacy solver.

    What SLEvolve solves¶

    SLEvolve solves the gravitationally self-consistent sea-level equation on a spherically symmetric viscoelastic Earth, including shoreline migration, marine ice grounding, rotational feedback and the outer iteration on the initial topography of ice age runs. The explicit load-history sum of the pseudo-spectral formulation is replaced by an exact recursive modal state, so the cost per time step does not grow with the length of the load history and the total cost grows as O(N) instead of O(N^2) in the number of time steps N. A Fortran solver derived from the legacy code of Han et al. (2022) and a Python solver written from scratch; the paper's version (Zenodo v1.0.0, doi 10.5281/zenodo.23422438) reproduces the legacy solver to round-off (below 1e-11 m in the three benchmark cases, with the Fortran and Python solvers identical to round-off); the current code additionally applies the corrected floating-ice convention, the corrected sign of the axial rotation component m3 and the corrected sign of the order-1 rotation records (see Provenance).

    Install and first run¶

    Get the code:

    git clone https://github.com/xiyuanbao/slevolve && cd slevolve

    Python (no install step; the quick start runs the Python solver):

    conda create -n slevolve -c conda-forge python=3.12 numpy numba ducc0 scipy netcdf4 matplotlib
conda activate slevolve
python examples/quickstart.py

    Fortran (build, then the Fortran test, which also needs the Python env above for the comparison):

    conda create -n slevolve-fortran -c conda-forge gfortran fftw openblas llvm-openmp
conda activate slevolve-fortran
CASE=case1 bash fortran/build.sh            # last line: built: .../fortran/build/case1/exe (...)
PYTHON="$(conda run -n slevolve which python)" bash tests/test_fortran_python.sh   # prints PASS

    Fortran only (no Python at all; toolchain from conda, Homebrew or apt, see Fortran without Python):

    bash tests/test_fortran_synthetic.sh        # builds, generates the synthetic Earth in Fortran, prints PASS
